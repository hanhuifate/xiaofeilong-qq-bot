# ChatGPT 普通聊天生图接入

用户已允许使用与桌面端相同账号的 ChatGPT 网页普通聊天。默认来源为 `chatgpt`，豆包可在控制中心手动选择，不会在失败后暗中切换或重复生成。此线路不是 OpenAI 图片 API，也不是 Codex 内置生图。

## 使用与设置

1. 先启动 QQ 回复服务，打开“查看后台.cmd”。
2. 首次双击项目根目录的 **ChatGPT生图登录.cmd**。安装器从 Google 官方下载 Chrome for Testing，校验官方存储返回的归档摘要与浏览器版本，记录本机 SHA256；使用独立浏览器配置，不复制桌面端或其他浏览器的登录资料。官方测试版没有数字签名，不能把这一点误判为签名损坏。
3. 在新打开的网页中登录与桌面端相同的 ChatGPT 账号。验证、密码和登录由本人完成。
4. 控制中心 → 本机管理 → 图片生成：确认“本机服务在线、扩展已连接、网页就绪”。可以调整默认来源、是否启用、桌面分组名、生成等待时间，以及启动、停止浏览器守护。
5. 在 QQ 中明确提出画图请求。普通的看图、投喂图片和闲聊不会自动发起生图。

本机兼容模式：官方测试版在这台电脑遇到 Windows SideBySide 启动错误，目前已选择系统安装的 Chrome，仍使用上表中的独立登录配置。首次在已打开的扩展页启用开发者模式，点“加载已解压的扩展”，选择 `extensions/chatgpt-images`。随后在控制中心点击“打开 ChatGPT 登录”完成自动配对和登录；以后无需重复加载。若需重新打开扩展页，可用面板相应按钮。可运行 `Setup-ChatGPT-Images.ps1 -UseInstalledChrome` 选择此模式，不修改日常 Chrome 的登录配置。

面板的“试画 1 张”会实际占用网页图片额度，只保存在本机并收纳聊天，不向 QQ 发送；同一请求 ID 重试不会重复生成。维护用 `node tools/verify-chatgpt-image.mjs` 也通过这条受鉴权线路验收，复用尚未完成的验证任务；只有明确传入 `--fresh` 才主动另开一次验证。

每项任务创建一个全新的普通聊天，不复用上一张图的上下文。浏览器只接收本次作图提示与比例，不接收 QQ 群号、成员身份、聊天历史或任意脚本。

默认整理进桌面侧栏自定义分组“图片”；这是桌面分组，不是网页版的 ChatGPT 项目。首次测试中，原有“生成图片”聊天已实际整理进去。新聊天同步到同一账号桌面端后，通过内置工具整理，不需要模型生成分组操作。

## 运行方式

```
QQ 明确画图请求 → qq_draw → 本机持久队列
  → 扩展在专用网页中新建聊天并提交一次
  → 观察同一聊天的生成结果
  → 读取网页实际展示的图片文件 → 本机校验、保存
  → QQ 回复服务把图片发回原聊天
  → 桌面原生工具将新聊天归入“图片”分组
```

等待、观察、取图和收纳由本机代码执行，没有持续 Codex 模型轮询。QQ 最初理解请求仍会使用当前聊天模型；网页生成使用 ChatGPT 账号的额度，无法从 Codex usage 精确推算图片剩余额度或费用。

扩展只操作自己创建的标签页，使用网页正常输入框和发送按钮。没有重放隐藏接口、提取 Cookie、读取令牌或启用远程调试端口。图片由页面实际加载的资源读取，直接传回本机；不调用浏览器下载按钮、Chrome downloads API 或迅雷。图片文件是网页提供的资源，不把网页截图冒充生成结果；不擅自声称其分辨率高于实际资源。

## 等待与恢复

- 图片文件通过类型、大小及 PNG 数据完整性检查后才记为完成，不能把“提示词已发出”记为生成成功。
- 默认参考等待时间 1200 秒。超过时间仍观察同一任务，在面板标为继续等待；不按时间直接宣布失败。
- 登录或验证中断会保留任务，人工完成后观察同一聊天；提交结果不确定时不会自动重发。
- 重启后，有已记录的聊天链接则打开原聊天继续取图；缺少链接且可能已经提交过时，停止自动提交，交由本人检查。
- 来源切换立即生效，已存在的任务保留自己的来源；不会把 ChatGPT 任务错误地交给豆包查询。
- QQ 暂时离线时保留成图，恢复连接后继续交付；QQ 发送结果不确定时保留记录，避免自动重复发图。
- 面板“取消等待”只停止本机跟进，不删除网页聊天，也不保证撤销已经提交到 ChatGPT 的生成。
- 桌面应用不在线、账号不同或尚未同步时，图片仍可保存和交付；分组保留待同步状态。

专用浏览器进程需要运行，可以最小化；关闭它会暂停观察。已在面板启用守护且默认来源为 ChatGPT 时，本机回复服务每 30 秒检查浏览器。电脑关闭、休眠或回复服务停机时不会继续工作。

## 文件位置

| 内容 | 位置 |
| --- | --- |
| 热更新设置 | `data/image-generation-settings.json` |
| 图片任务 | `data/chatgpt-image-jobs.json` |
| QQ 图片交付记录 | `data/image-deliveries.json`，旧豆包记录保留 |
| 图片文件 | `outputs/chatgpt-images/<聊天哈希>/` |
| 网页扩展源码 | `extensions/chatgpt-images/` |
| 专用浏览器与登录配置 | `%LOCALAPPDATA%\Xiaofeilong\ChatGPTImages\` |

本机图片工作接口仅监听 `127.0.0.1:6103`，与控制中心、AstrBot 和原来的登录辅助端口分开；使用独立随机连接码和任务租约。面板不返回工作接口连接码或浏览器凭据。

## 验证边界

已验证：本机鉴权与来源限制、任务租约、重启恢复、旧聊天不得复用、超时后继续等待、图片校验及重复上传幂等、来源切换、面板设置与取消等待；已有普通生图聊天已实际归入“图片”。

尚需首次网页登录后的真实验收：扩展在当前 ChatGPT 网页版本发送请求、取回实际成图并保存，以及经现有 QQ 发图链路回传。安装状态或服务在线不能代替这项验收。

完整本机检查：`node --test *.test.mjs`。实际生图检查会占用网页账号额度，应控制次数；不向真实 QQ 群发送模拟测试消息。

官方浏览器来源：[Chrome for Testing 发布列表](https://googlechromelabs.github.io/chrome-for-testing/)，[Google 维护者关于测试版未签名的说明](https://github.com/GoogleChromeLabs/chrome-for-testing/issues/205)。
