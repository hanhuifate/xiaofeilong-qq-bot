# ChatGPT 普通聊天与 Codex 内置生图：单次实测

日期：2026-10-27。账户接口报告 Plus。本次只各生成一张，不调用付费图像 API、不购买额度、不重置额度、不使用迅雷下载。

## 结果

| 入口 | 实际完成 | 可读取的额度结果 |
| --- | --- | --- |
| ChatGPT 桌面端普通聊天 | 已提交至既有「生成图片」聊天，用户确认已显示这张测试图 | 当前原生工具只提供 Codex 用量池，没有普通聊天独立图片额度的数值；无法给出本张精确消耗 |
| Codex 内置 image_gen | 成图成功，本地保存并显示 | 5 小时池已用 57% → 58%，周池已用 64% → 65%；显示值各增加 1 个百分点 |

这不是“ChatGPT 一张消耗 4%、Codex 一张消耗 1%”的对照，也不能据此确定普通聊天和 Codex 生图谁更省。

## 相同提示词

> 生成一张正方形插画，目标尺寸1024×1024，只生成一张。画面是一位成年白发龙角少女坐在木桌旁，手里拿着一颗蓝色水晶，窗外是夜空，柔和灯光，干净的二次元插画风格。不要文字、水印或拼图。

ChatGPT 普通聊天复用了原有图片聊天，含此前少量上下文；Codex 使用当前任务的内置生图工具。即使提示词一致，这也不是严格同上下文、同参数的性能基准。

Codex 成图实际为 **1254 × 1254**，约 2.48 MB；工具没有保证提示中要求的 1024 × 1024。普通聊天实际图像尺寸没有从接口取得，不能假定一致。

## 原始观测

以下时间为北京时间，百分比均为“已使用”，不是剩余。

| 时点 | 5 小时池 | 周池 | 说明 |
| --- | ---: | ---: | --- |
| 23:18:36 普通聊天提交前 | 53% | 64% | 原生用量接口只返回 codex 池 |
| 23:22:55 普通聊天阶段结束 | 57% | 64% | 这段包含 QQ 一次模型调用及本任务操作，不能归因给图片 |
| 23:23:28 Codex 生图前 | 57% | 64% | QQ 模型调用已暂停，队列/活动聊天为零 |
| 23:25:31 Codex 生图后 | 58% | 65% | QQ 用量记录数和 token 总量均没有增加 |
| 23:26:16 再次读取 | 58% | 65% | 显示值与立即读取一致 |

普通聊天阶段有 1 次 QQ 模型调用，记录的输入加输出为 49,576 token。该阶段 Codex 额度的 4 个百分点变化不能当作普通聊天图片消耗。

Codex 测量区间约 123 秒，包含工具调用与用量读取。其间 QQ 用量记录为 129 条、累计 6,219,541 token，前后相同。原先全局暂停状态为 false，测量后已恢复为 false。

## 读数边界

- 用量接口返回整数百分比，不是每张图片的精确账单。显示增加 1 个百分点，不等于以后每张固定扣 1%。
- Codex 区间排除了 QQ 新调用，但账户变化仍可能包括当前测量会话、统计延迟及其他未观测活动；不能把账户变化完全解释成纯图片计算量。
- 图像工具没有返回可单独核算的图片 token 或费用，所以没有反推 API 金额或订阅可画张数。
- 普通聊天接口返回了请求记录，未返回成图附件，本次成图成功由用户明确确认。现有工具不能读取普通聊天图片池的精确数值。
- 本次只有各一张样本，不代表平均消耗、每日张数上限或固定套餐保证。
